# Inkspire Capi - Creative Agency & Digital Strategy

**Inkspire Capi** is an agency that merges the precision of printing systems with the power of modern web development. As **Lead Developer & UX Strategist**, I direct the agency's technological evolution, creating digital ecosystems where creativity and performance converge.

## Main Features

- **High-Performance Architecture:** Implementation based on Astro to achieve ultra-fast loading and optimized efficiency.
- **Immersive User Experience:** Use of advanced animations and smooth scrolling for a high-end navigation experience.
- **UX/UI Strategy:** Interface design focused on conversion, visual ergonomics, and brand identity.
- **Security & Scalability:** Standardization of security protocols and constant audits of the technological infrastructure.
- **Digital-Analog Fusion:** An ecosystem that unites the power of web development with the precision of professional printing.

### Key Responsibilities and Achievements:

- **Lead the agency's technological evolution** as Lead Developer and UX Strategist.
- **Developed the main platform using Astro**, prioritizing global performance and accessibility.
- **Implemented complex animations with GSAP**, elevating the visual quality and interactivity of the interface.
- **Integrated Lenis for Smooth Scroll**, ensuring a fluid and unified user experience across different browsers.
- **Established development standards with TypeScript** to ensure maintainable, secure, and scalable code.
- **Designed the touch and desktop interface in Figma**, ensuring a seamless transition between creative concept and technical execution.
