# GRN Agroindustrial

**GRN Agroindustrial** is the website for one of the companies under Grupo Remolques del Norte, specializing in the sale of machinery for the agricultural and industrial sectors. The site features a complete catalog of the products offered, as well as tools designed to help customers select the specific machinery they need. The infrastructure was deployed using Coolify instead of Google Cloud Platform (GCP).

## Main Features

- Complete catalog of agricultural and industrial machinery with detailed technical specifications.
- User assistance tools for equipment selection.
- Multimedia gallery of products and real-world applications.
- Responsive design optimized for all devices.

### Key Responsibilities and Achievements:

- **Led the complete UX/UI design** in Figma, creating an intuitive and visually appealing information architecture.
- **Developed the full implementation in Next.js** using React and TypeScript with a scalable architecture.
- **Implemented advanced SEO and SSR strategies**, optimizing performance and search engine visibility.
- **Optimized performance by 80%**, reducing initial load times to under 1.5 seconds.
- **Significantly improved accessibility**, complying with WCAG 2.1 AA standards for digital inclusivity.
- **Established proactive security protocols**, implementing periodic version reviews and data encryption.
